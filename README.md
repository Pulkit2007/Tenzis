# Tenzies 🎲

A simple Tenzies dice game built with **React**.

The objective is to roll the dice until all ten dice show the same number. Players can hold individual dice to keep their values while rolling the remaining dice.

The project focuses on practicing React fundamentals such as **state management, event handling, component-based design, conditional rendering, and working with arrays of objects**.

## Setup & Run

Clone the repository:

```bash
git clone <repository-url>
cd tenzies
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal to play the game.
